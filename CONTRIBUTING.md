# Contributing

Thanks for helping grow this list!

## Ways to contribute
- Add a guide for another FOSS alternative (for example, Bitwarden instead of a proprietary password manager)
- Fix typos, broken links, or outdated install steps
- Improve an existing guide with screenshots or tips

## How
1. Fork this repo
2. Create a branch: `git checkout -b add-<tool-name>`
3. Copy an existing file in `tools/` as a template
4. Commit and open a pull request describing your change

Issues labelled `good first issue` are a great place to start.
