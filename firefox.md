# Firefox (alternative to Chrome)

**What it is:** A free, open-source browser from the non-profit Mozilla.

**Why switch:**
- Enhanced Tracking Protection blocks many trackers by default
- Container tabs keep sites separated
- Large library of extensions

**Install:** https://www.mozilla.org/firefox

**Quick start:**
1. Install Firefox
2. Import bookmarks and passwords from Chrome when prompted
3. Set Firefox as your default browser
4. Click the shield icon in the address bar to see what it blocked on a site

**Things to know:** Most sites work identically. Chrome extensions are not directly compatible, but most popular ones have Firefox versions.
