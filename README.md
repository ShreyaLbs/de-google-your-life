# De-Google Your Life 🔓

> 5 apps you already know, reinvented — free, open, yours.

A hands-on workshop by the **FOSS Club, LBS Institute of Technology for Women** exploring free and open-source alternatives to everyday big-tech tools.

## The 5 Swaps

| Instead of | Use | Get it |
|---|---|---|
| WhatsApp | Signal | [signal.org/download](https://signal.org/download) |
| MS Office | LibreOffice | [libreoffice.org/download](https://www.libreoffice.org/download) |
| Chrome | Firefox | [mozilla.org/firefox](https://www.mozilla.org/firefox) |
| Google Drive | Nextcloud / Syncthing | [nextcloud.com/install](https://nextcloud.com/install) / [syncthing.net/downloads](https://syncthing.net/downloads) |
| Google Search | DuckDuckGo | [duckduckgo.com](https://duckduckgo.com) |

## Try It Yourself

Follow the [checklist](checklist.md) and swap at least 3 tools.

## Check What Google Knows About You

- Activity: https://myactivity.google.com
- Data & Privacy: https://myaccount.google.com/data-and-privacy

## Workshop Flow (1 hour)

| Time | Segment | What happens |
|---|---|---|
| 0:00-0:05 | Cold Open: Data Reveal | Check your own Google activity and location history |
| 0:05-0:30 | Swap Battles | Live head-to-head demos of each swap, with a poll after each round |
| 0:30-0:50 | Install & Win Challenge | Install at least 3 of the 5 tools, with help from volunteers |
| 0:50-1:00 | One Thing You're Keeping | Share the one tool you'll keep using |
