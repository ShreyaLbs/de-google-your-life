# Session Plan (1 hour)

| Time | Segment | What happens |
|---|---|---|
| 0:00-0:05 | Cold Open: Data Reveal | Attendees open myactivity.google.com and Maps Timeline on their own phones, scroll silently, then a few share what they found |
| 0:05-0:30 | Swap Battles | Five live head-to-head demos, with a show-of-hands poll after each |
| 0:30-0:50 | Install & Win Challenge | Attendees work through the [checklist](../checklist.md); volunteers help |
| 0:50-1:00 | One Thing You're Keeping | Each attendee names the one tool they will keep using |

See [swap-battles.md](swap-battles.md) for the demo details.
