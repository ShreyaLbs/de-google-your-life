# Signal (alternative to WhatsApp)

**What it is:** A free, open-source messaging app with end-to-end encryption on by default.

**Why switch:**
- Messages and calls are end-to-end encrypted by default
- Collects minimal user data
- Disappearing messages and screen security built in

**Install:** https://signal.org/download (Android, iOS, Desktop)

**Quick start:**
1. Install and register with your phone number
2. Set a PIN when prompted
3. Invite a friend and send your first message
4. Try disappearing messages: open a chat, tap the name, choose "Disappearing messages"

**Things to know:** Your contacts need Signal too. You can keep using WhatsApp alongside it.
