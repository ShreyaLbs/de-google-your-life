# LibreOffice (alternative to MS Office)

**What it is:** A free, open-source office suite with Writer (documents), Calc (spreadsheets), and Impress (presentations).

**Why switch:**
- Free, with no subscription
- Opens and saves .docx, .xlsx, and .pptx files
- Exports to PDF in one click

**Install:** https://www.libreoffice.org/download

**Quick start:**
1. Install and open Writer
2. Open an existing .docx file to check formatting
3. Use File > Export as PDF
4. To save in Word format, choose File > Save As > Word 2007-365 (.docx)

**Things to know:** Complex formatting can sometimes shift slightly when files move between LibreOffice and MS Office, so check important documents before submitting.
