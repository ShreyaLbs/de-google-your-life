# Swap Battles

1. **WhatsApp vs Signal:** send the same message on both; compare privacy settings and disappearing messages
2. **Chrome vs Firefox:** load the same news site on both; compare tracker counts
3. **Google Drive vs Nextcloud/Syncthing:** show a file syncing between two devices live
4. **Google Search vs DuckDuckGo:** search the same query side by side; compare ads and tracking
5. **MS Office vs LibreOffice:** open the same .docx in both

After each round, ask: "Which would you actually switch to?"
