# Nextcloud / Syncthing (alternative to Google Drive)

**What they are:** Open-source ways to sync and share files without handing them to a big-tech provider.

- **Syncthing:** syncs folders directly between your own devices, with no central server
- **Nextcloud:** a self-hostable cloud storage platform (files, calendar, contacts); some providers offer hosted accounts

**Why switch:**
- You control where your files live
- Syncthing needs no account and no cloud storage

**Install:**
- Syncthing: https://syncthing.net/downloads
- Nextcloud: https://nextcloud.com/install

**Quick start (Syncthing):**
1. Install Syncthing on two devices
2. Open the web interface and note each device ID
3. Add the other device using its ID and accept on both sides
4. Share a folder and watch it sync

**Things to know:** Syncthing syncs between devices that are online, so it is not an always-on cloud. For that, use Nextcloud on a server.
